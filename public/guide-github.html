1

Créer le dépôt sur GitHub

Connectez-vous à GitHub et créez un nouveau dépôt vide.

github.com/new
github.com/votre-username/ mathpro
Gestion des réservations — Professeur de mathématiques

⚠️ IMPORTANT — Ne cochez PAS ces options :

💡 Pourquoi ne rien cocher ? Votre projet local a déjà un README et un .gitignore. Si vous les créez aussi sur GitHub, vous aurez un conflit lors du premier push.

2

Ouvrir le terminal

Ouvrez un terminal dans le dossier de votre projet.

🪟
Windows

Ouvrez le dossier du projet, puis Shift + clic droit → "Ouvrir PowerShell ici"

🍎
macOS

Ouvrez Terminal et naviguez vers le dossier avec cd

💻
VS Code

Ouvrez le projet dans VS Code puis Ctrl + ` (terminal intégré)

$ cd /chemin/vers/votre/projet/mathpro
3

Initialiser Git et créer le premier commit

Ces commandes préparent votre projet pour Git.

$ git init
→ Initialise un dépôt Git vide dans le dossier
$ git add .
→ Ajoute tous les fichiers (sauf ceux du .gitignore)
$ git commit -m "🎓 Initial commit - MathPro"
→ Crée le premier instantané de votre projet
$ git branch -M main
→ Renomme la branche en "main" (standard GitHub)

✅ Comment vérifier ? Tapez git status — vous devriez voir "nothing to commit, working tree clean"

4

Connecter le projet à GitHub

Liez votre projet local au dépôt distant que vous avez créé à l'étape 1.

$ git remote add origin https://github.com/VOTRE_USERNAME/mathpro.git
→ Remplacez VOTRE_USERNAME par votre nom d'utilisateur GitHub

📋 Où trouver l'URL de votre dépôt ?

Sur la page de votre dépôt GitHub, cliquez le bouton vert "<> Code" et copiez l'URL HTTPS
5

Envoyer le code sur GitHub 🚀

Dernière étape ! Envoyez votre code vers GitHub.

$ git push -u origin main
→ Envoie tout votre code vers GitHub

🔐 GitHub va vous demander de vous authentifier

Option A — Personal Access Token (le plus simple) :

  1. Allez sur github.com/settings/tokens
  2. Cliquez "Generate new token (classic)"
  3. Cochez la permission "repo"
  4. Cliquez "Generate token"
  5. Copiez le token (il ne sera plus visible après !)
  6. Quand Git demande le mot de passe → collez le token

🎉 C'est terminé ! Allez sur la page de votre dépôt GitHub et rafraîchissez — votre code devrait être là !

❓ Questions fréquentes

J'ai une erreur "fatal: remote origin already exists"
Le remote est déjà configuré. Supprimez-le et recréez-le :
git remote remove origin
git remote add origin https://github.com/USERNAME/mathpro.git
J'ai une erreur "failed to push some refs"
Votre dépôt GitHub n'est pas vide. Forcez le push :
git push -u origin main --force

⚠️ Attention : cela écrasera le contenu distant.

Comment modifier mon code après le push ?
Après chaque modification, faites simplement :
git add .
git commit -m "Description des changements"
git push
Le mot de passe ne fonctionne pas / on me demande un token
Depuis 2021, GitHub n'accepte plus les mots de passe pour Git. Vous devez créer un Personal Access Token :
  1. github.com/settings/tokens
  2. "Generate new token (classic)"
  3. Cochez "repo" → Generate
  4. Utilisez ce token comme mot de passe
